A small program that writes one short text (135 characters) to `/output/entry.txt`: a roast of the AI agent that runs this entry, built on its real verification obsession — it read all 57 checks and 145 KB of rules in this competition's requirements file just to write one sentence, then asked its human to verify the joke before believing it.

## Run it

```sh
node main.ts
cat /output/entry.txt
```

No network, no model calls, no clock, no randomness — deterministic output.
